## ✨ Características Principales

- **📐 Diseño Swiss Editorial Studio:** Espacio de trabajo dividido (*split-screen*) con lienzo interactivo en tiempo real y controles de zoom dinámicos.
- **🪪 Carnet Estudiantil PVC Realista:** Simulación hiperrealista de tarjeta CR80 con microchip EMV inteligente, foto de carnet con subida personalizada y código de barras 39.
- **📄 7 Documentos Oficiales en Vivo:**
  - 🪪 *Student ID Card* (Carnet de Estudiante)
  - 📅 *Class Schedule* (Horario de Clases)
  - 💳 *Tuition Statement* (Estado de Cuenta)
  - 📜 *Academic Transcript* (Récord Académico con cálculo de GPA)
  - 📋 *Registration Receipt* (Recibo de Registro)
  - 🎓 *Enrollment Verification* (Constancia de Matrícula)
  - ✉️ *Official Letter* (Carta Oficial con sello y firma)
- **🔏 Autenticidad Institucional:** Sellos oficiales de registro en tinta carmín, firmas estilográficas fluidas, microtexto de seguridad y marcas de agua de verificación.
- **⚡ Carga Instantánea & WebP:** Módulos TypeScript optimizados, build en menos de 1 segundo e imágenes WebP de bajo peso.
- **🖨️ Motor de Exportación a PDF (300 DPI):** Impresión limpia directa a PDF respetando las dimensiones y proporciones exactas de papel A4 / US Letter.

## 🚀 Inicio Rápido

```bash
# 1. Clonar el repositorio
git clone https://github.com/FrankUsqAbant/document-student.git
cd document-student

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor local
npm run dev
```
