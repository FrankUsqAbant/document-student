## 🌟 Características Destacadas

| Función | Descripción |
| :--- | :--- |
| **📐 Swiss Editorial Studio** | Espacio unificado con previsualización en vivo A4 y controles rápidos en panel carbón. |
| **🪪 Carnet Estudiantil PVC** | Tarjeta física CR80 con microchip inteligente EMV, código de barras y foto personalizada. |
| **📄 7 Documentos Oficiales** | Carnet, Horario, Estado de Cuenta, Récord Académico (GPA), Recibos y Cartas Oficiales. |
| **🔏 Fidelidad Gráfica** | Sellos oficiales de registro en tinta azul, firmas estilográficas y microtexto de seguridad. |
| **⚡ Rendimiento Máximo** | Carga en frame 0 sin parpadeo de color, WebP optimizado y 0 vulnerabilidades. |
| **🖨️ Exportación 300 DPI** | Motor de impresión directo a PDF respetando las dimensiones y proporciones exactas. |

## 🚀 Inicio Rápido

```bash
# Clonar el proyecto
git clone https://github.com/FrankUsqAbant/document-student.git
cd document-student

# Instalar dependencias e iniciar
npm install
npm run dev
```
